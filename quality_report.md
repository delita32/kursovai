# Отчёт о качестве

1. Тема определена по зачётке: 6 → «Информационная мера Р. Хартли».
2. Титульный лист присутствует.
3. Содержание присутствует.
4. Пункт «Содержание» не включён внутрь содержания.
5. Введение присутствует.
6. Есть минимум две главы.
7. В первой главе есть минимум два параграфа (1.1, 1.2, 1.3).
8. Заключение присутствует.
9. Список источников присутствует.
10. Таблица создана как настоящая таблица Word (`w:tbl`).
11. Формула дана текстовым математическим блоком, не изображением.
12. Рисунок создан отдельным PNG и встроен в DOCX.
13. В тексте есть ссылки на рисунок, таблицу и формулу.
14. После рисунка, таблицы и формулы добавлены поясняющие абзацы.
15. В тексте есть ссылки на источники [1], [2], [3].
16. Поля заданы в OpenXML: 30/15/20/20 мм (эквиваленты twips).
17. Шрифт задан Times New Roman 14 пт.
18. Межстрочный интервал задан 1,5.
19. Абзацный отступ задан 1,25 см.
20. Объём ориентирован под ~30 страниц, точное значение проверить в Microsoft Word.
21. Ручная проверка обязательна: точная пагинация, актуальность ФИО зав. кафедрой, финальная типографика.

Документ создан без внешних зависимостей (только стандартная библиотека Python и ручная сборка OpenXML).
