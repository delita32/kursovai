# Сводка требований

- Тема по последней цифре зачётки: **6 → Информационная мера Р. Хартли**.
- Обязательные элементы: титульный лист, содержание, введение, минимум 2 главы (в одной ≥2 параграфов), заключение, список источников, рисунок, формула, таблица.
- Объём: ровно 30 страниц (фактически проверяется вручную в MS Word).
- Оформление: A4, поля 30/15/20/20 мм, TNR 14, 1.5 интервал, красная строка 1.25 см, выравнивание по ширине.
- Нумерация страниц: снизу по центру; на титуле номер не отображается.
- Разделы с новой страницы: СОДЕРЖАНИЕ, ВВЕДЕНИЕ, главы, ЗАКЛЮЧЕНИЕ, СПИСОК ИСТОЧНИКОВ.
- Заголовки структурных элементов: по центру, ПРОПИСНЫМИ, без точки.
- В содержании не писать «Содержание» как пункт.
- Таблица/формула/рисунок не должны быть скриншотами.
- Перед рисунком/таблицей/формулой должна быть ссылка в тексте; после каждого элемента — поясняющий абзац.
- Ссылки на источники в тексте: [1], [2], ... ; список источников — в порядке упоминания.
